# Postman: локальный API

Коллекция [`shadow-fleet-local.postman_collection.json`](shadow-fleet-local.postman_collection.json) содержит запросы к списку позиций, карточке MMSI проверкам ошибок, истории AIS и досье. Переменные коллекции: `base_url` (по умолчанию `http://127.0.0.1:8000`) и `mmsi`. Для истории задайте UTC-границы `history_from` / `history_to`, для досье — `dossier_on`. Значения по умолчанию пригодны для проверки схемы и могут вернуть пустое окно. В коллекции нет токенов и паролей.

В приложении Postman войдите в аккаунт, выберите рабочее пространство, затем **Import** и выберите JSON-файл коллекции. В режиме без аккаунта установленная версия Postman предлагает только Lightweight API Client, без сохранения коллекций. В зависимости от настроек рабочего пространства импорт может синхронизировать коллекцию с Postman; не добавляйте в неё секреты.

Запустите БД и API по [инструкции API](../docs/api/v1.md). Выберите запрос и нажмите **Send**. Запрос карточки для отсутствующей позиции ожидаемо вернёт 404; пустой список также допустим. Сборщик находится на стадии проверки; живые позиции поступают только при его отдельном запуске.

В Codex добавлен официальный удалённый Postman MCP `https://mcp.postman.com/minimal`. Для подключения к аккаунту требуется OAuth-вход: `codex mcp login postman`. После авторизации может потребоваться открыть новую сессию Codex. Удалённый MCP предоставляет доступ к ресурсам аккаунта Postman и не может обращаться к `127.0.0.1` этого компьютера; локальные запросы выполняйте в приложении Postman или локальным runner. Подключение MCP само по себе не импортирует этот JSON в аккаунт.

Проверка коллекции через Newman (после установки Newman отдельно) выполняется локально:

```sh
newman run postman/shadow-fleet-local.postman_collection.json
```

Для другого порта используйте `--env-var base_url=http://127.0.0.1:PORT`. Инструкция не требует записывать DSN или API-ключи в коллекцию.

2026-11-14: коллекция импортирована в личное рабочее пространство Postman; семь запросов отображаются. OAuth-подключение Postman MCP к Codex подтверждено владельцем.
