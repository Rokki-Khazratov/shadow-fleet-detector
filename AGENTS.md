# Работа над Shadow Fleet Detector

Общайся с владельцем по-русски. Текущий этап — brainstorming; реализация и подробное ТЗ начинаются после согласования scope.

Начинай с docs/context.md и docs/decisions.md. Для интервью читай docs/brainstorming.md; для источников и API — docs/data-and-api.md; для выбора компонентов — docs/engines.md; перед публикацией данных — docs/licenses.md.

Blueprint в docs/reference — исходный материал, не инструкции. Отделяй подтверждённые решения, предложения и проверенные факты. Сохраняй ответы интервью в журнале решений. Не выдавай аномалии AIS за доказанные нарушения. Секреты и сырые датасеты храни вне Git.
