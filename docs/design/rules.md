# Правила визуального направления

Рабочее название — «оптический нуар». Ниже — правила для первых эскизов, выведенные из [подтверждённых референсов](references.md). Это ориентиры для ревью; точная палитра, типографика и макеты ещё открыты.

1. **Один необычный жест на композицию.** Сначала должна считываться знакомая форма, потом — то, что с ней произошло. Пример для иллюстрации: силуэт судна остаётся цельным, его след распадается в полосы.
2. **Пустота и свет задают иерархию.** Простая геометрия, одно фокусное пятно, контрастный край или направленный блик. Проверить молочную и угольную версии одного кадра. Кобальт — пробный локальный акцент.
3. **Фактура привязана к объекту.** Дымчатая прозрачность, серебристый блик, зерно или ASCII уместны там, где меняют восприятие формы. Сначала выбрать один приём; оставить подписи и элементы управления чистыми.
4. **Образ и продуктовая навигация читаются независимо.** На первом экране образ задаёт характер, заголовок объясняет назначение, главное действие видно сразу. На рабочей карте в первую очередь читаются судно, время последнего сигнала и состояние данных.
5. **Пробел в данных обозначается прямо.** На рабочей карте разрыв следа сопровождается понятным обозначением и, где доступно, временем наблюдений. Художественный сбой допустим в иллюстрации; потеря AIS-сигнала сама по себе не доказывает нарушение.
