# План discovery

Это план обсуждения, не план реализации.

- Сохранить исходный материал и подтверждённые пожелания.
- Выяснить личную цель, пользователя и решение, которое помогает принять продукт.
- Сопоставить 2–3 сценария MVP с доступными данными.
- Проверить официальные источники, условия доступа, лицензии и маленький образец данных.
- Выбрать регион, период, класс судов и критерии качества.
- Обсудить объяснимость и ложные срабатывания.
- Вернуться к визуальному направлению.
- Зафиксировать согласованный scope; только затем писать ТЗ.

Готовность к ТЗ: согласованы пользователь, сценарий, данные, ограничения, критерии успеха и исключения.
