# История наблюдений — v0.2 draft

История дополняет текущую карту v0.1. Она доступна по источнику и MMSI: такой ключ обозначает AIS-сигнал. Сопоставление судов между источниками в этот срез не входит.

`GET /v1/history/fintraffic/123456789?from=2026-11-15T10:00:00Z&to=2026-11-15T11:00:00Z&limit=100` принимает UTC-время (`Z` или `+00:00`) и окно `[from,to)` длиной до 7 суток. По умолчанию возвращает до 1 000 сохранённых наблюдений в порядке времени, с `source`, `mmsi`, `items` и флагом `truncated`. Следующее окно можно начать сразу после последней полученной временной отметки. Неизвестный источник — 404, неверное окно/MMSI/лимит — 400, недоступная БД — 503. Пустой список означает отсутствие сохранённых наблюдений в окне. Кеширование отключено.

В таблице одна сведённая позиция на секунду источника, с той же политикой выбора REST/MQTT, что в текущей проекции. Сохраняются время, точность, канал, координаты и признаки конфликта, а не исходные сообщения. Из истории старше 7 суток API ничего не выдаёт; активный сборщик удаляет просроченные строки порциями раз в минуту. Пока сборщик остановлен, физическая очистка ожидает следующего запуска. Запись выключена по умолчанию. Нет автоматического импорта архивов или ретроспективного восстановления точек.

Перед использованием примените миграции и выдайте роли API `SELECT` на `position_history`. `python -m shadow_fleet collect --history` включает запись и обращается к реальному Fintraffic. В карточке можно запросить первые 100 точек за 1, 6 или 24 часа до последнего снимка карточки. Интерфейс показывает фактические границы UTC и сообщает об усечении. Точки выделены на карте отдельным слоем, открываются по клику и очищаются при выборе другого сигнала. Интерфейс не соединяет их линиями. Ответ также содержит [сводку качества](quality.md).
