# Локальный API v1 — draft

FastAPI предоставляет интерактивную схему `/docs` и OpenAPI `/openapi.json`. API не обращается к поставщику AIS: он читает последнюю сохранённую проекцию PostgreSQL. Сетевой сборщик находится на стадии проверки; новые наблюдения появляются только при его запуске и работающем источнике.

- `GET /v1/positions?west=-180&south=-90&east=180&north=90` — до 2 000 позиций и `truncated`; bbox обязателен. Пересечение антимеридиана задаётся `west > east`.
- `GET /v1/positions/fintraffic/123456789` — позиция одного MMSI, либо 404.

Оба ответа содержат единое UTC-время `as_of`, атрибуцию и состояние источника. Позиции старше 24 часов исключаются; `stale` означает возраст более 300 секунд. После начала работы сборщика устаревший heartbeat переводит состояние в `degraded`; `live` также становится `degraded` при отсутствии свежего MQTT-сообщения. До первого запуска источник остаётся `starting`. MMSI — идентификатор наблюдаемого сигнала, не установленная личность судна. Никаких выводов о нарушениях или принадлежности к теневому флоту API не делает.

Ошибки имеют вид `{"error":{"code":"invalid_bbox","message":"..."}}`; коды: `invalid_bbox`, `invalid_mmsi`, `not_found`, `database_unavailable`. Все ответы содержат `Cache-Control: no-store`. Данные и состояние читаются в одной read-only транзакции repeatable read; сетевое подключение ограничено 3 секундами, отдельный SQL-запрос — 5 секундами.

## Локальный запуск

Установите зависимости из `requirements.lock` и пакет editable (`uv pip install --python .venv/bin/python -r requirements.lock` и `uv pip install --python .venv/bin/python -e .`). Примените миграции через `SFD_DATABASE_URL` и `python -m shadow_fleet migrate`. Для API задайте **отдельный** `SFD_API_DATABASE_URL`, ссылающийся на роль, которой выданы только `CONNECT` к нужной БД, `USAGE` на схему `public` и `SELECT` на таблицы `source`, `source_state`, `latest_position` и `position_history` (для [истории v0.2](history.md)). Не используйте владельца БД; для новой роли задавайте пароль в безопасном интерактивном окружении и держите DSN вне Git.

```sh
.venv/bin/python -m shadow_fleet api --port 8000
```

Сервер привязан к `127.0.0.1`; аутентификация, TLS и публичное развёртывание не реализованы. `--port` необязателен. Транзакция API принудительно read-only, но это не заменяет отдельную роль БД: ограничение привилегий зависит от фактически настроенной роли.
