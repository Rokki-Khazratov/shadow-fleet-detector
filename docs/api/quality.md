# Качество наблюдений AIS — v0.4 draft

Ответ истории дополнен объектом `quality`. Счётчики `observed_points`, `conflict_count` и `clock_skew_count` описывают только точки в этом ответе. Конфликт означает разные измерения в одной секунде; сдвиг времени берётся из нормализации.

При `interval_status: assessed` (`items` не усечены, есть хотя бы две точки) `long_interval_count` считает соседние сохранённые точки с интервалом от 900 секунд включительно. `long_intervals` содержит первые десять случаев с границами и длительностью. Интервал до первой или после последней точки не измеряется. `truncated` и `insufficient` в `interval_status` означают, что оценка интервалов отсутствует: счётчик `null`, список пустой.

Порог 15 минут — локальный критерий для просмотра, не норма по доступности AIS. Причина интервала неизвестна: окно зависит от покрытия и работы сборщика. Сводка не выводит отключение передатчика, нарушение, санкции или принадлежность к теневому флоту. В карточке её можно раскрыть под сохранёнными наблюдениями; внешний каталог в расчёте не используется.
