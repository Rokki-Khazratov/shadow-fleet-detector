# Локальное досье сигнала — v0.3 draft

`GET /v1/dossier/{source_id}/{mmsi}?on=2026-11-15` возвращает записи операторского каталога на указанную дату UTC. Карточка передаёт дату выбранного наблюдения. Если `on` пропущена, API использует текущую дату UTC. Допустимые состояния: `not_configured`, `no_link`, `linked`, `ambiguous`. Отсутствие записи в каталоге не устанавливает статус судна.

Каталог загружается при старте API только при заданном `SFD_DOSSIER_CATALOG`. Файл JSON — до 512 КиБ, до 1000 связей и 1000 внешних записей. [Синтетический пример](../../tests/fixtures/dossier-synthetic.json) описывает формат. Реальный каталог храните вне Git, например под `data/`. Каждая запись требует ссылки HTTPS, названия источника, даты получения и примечания об условиях использования. Некорректный файл приводит к ошибке запуска. API не загружает URL.

Связь относится к одному ключу `source_id + mmsi` и дневному полуоткрытому интервалу `[since, until)`. Внешние записи присоединяются по точному `namespace + identifier` и `published_on <= on`. Если одновременно указаны разные ключи, показываются альтернативы со ссылками, но внешние утверждения не присоединяются. Совпадения имени, близости координат и MMSI без явной связи не используются.

`authority_notice` и другие записи — цитируемые утверждения источника; по ним не выводится актуальный статус, нарушение или принадлежность к теневому флоту. Карта по-прежнему отображает текущий Fintraffic. Автоматическое объединение источников и импорт сторонних реестров требуют отдельно проверенных данных и прав.
