# Следующие локальные этапы — draft

Рабочий порядок для самостоятельной разработки. Локальная приёмка проходит на синтетике; для реального покрытия, импорта архивов и публикации действуют отдельные ограничения проекта.

- [x] Этап 2: добавить слой сохранённых точек выбранного MMSI. Проверить просмотр точки, сброс при смене карточки и отсутствие линий между наблюдениями.
- [x] Этап 3: добавить локальное досье. Загружать подготовленный оператором JSON только по явной настройке. Привязка внешнего идентификатора к сигналу ограничена интервалом и ссылкой на первичный источник; конфликтующие связи показываются раздельно. Отдельный раздел внешних утверждений, никакого вывода о статусе судна.
- [x] Этап 4: показывать признаки качества сохранённых наблюдений — интервалы между точками и конфликты времени. В отчёте указывать порог и границы: интервал говорит о наблюдениях приложения; усечённая выборка не оценивается как целое окно. Держать признаки отдельно от внешних утверждений.
- [x] Этап 5: воспроизводимый локальный прогон, сверка инструкций и перечень условий для публичного запуска. Включить браузер и PostGIS в итоговую приёмку.
