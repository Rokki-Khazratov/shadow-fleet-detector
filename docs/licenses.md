# Лицензии и публикация

Лицензия собственного кода и документации ещё не выбрана. Файл LICENSE намеренно не выдаёт неподтверждённое разрешение от имени владельца. Публичность репозитория сама по себе не заменяет лицензию.

Отдельно учитывать: код проекта; документацию; внешние библиотеки; исходные данные; производные данные; карты, шрифты и изображения. Условия кандидатов нужно проверить по официальным источникам до включения в распространяемый продукт.

Вопрос владельцу на следующем этапе: предполагается ли коммерческое использование и какое повторное использование проекта он хочет разрешить?

Исходный blueprint предоставлен пользователем для включения в контекст и публикации документации; внешние датасеты в репозиторий не включены.
