# Данные и API: исследовательский реестр

Статус всех кандидатов: упомянуты в blueprint, независимо не проверены. Официальные ссылки — в [реестре источников](reference/sections/19.md).

| Кандидат | Предполагаемая роль | Что проверить |
|---|---|---|
| NOAA | Исторические AIS positions | Реальная гранулярность файлов, регион, период, лицензия |
| Danish AIS | История AIS | Доступ, объём, условия повторной публикации |
| Norway AIS | AIS | Покрытие, ограничения, архивы |
| AISstream | Поток AIS | Ключ, покрытие, лимиты, хранение |
| Global Fishing Watch | Производные события | Отличие от raw AIS, доступ, атрибуция |
| OpenSanctions | Идентичность и списки | Совпадения, условия использования данных |

Карточка проверки: URL; дата; версия условий; способ доступа; sample; схема; покрытие; задержка; пропуски; стоимость; лимиты; хранение; перераспространение; атрибуция.

Собственный API пока не спроектирован. Его потребители и функции зависят от выбранного сценария.
