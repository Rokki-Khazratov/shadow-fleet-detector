# Первый промпт для модели-разработчика

Скопируйте текст ниже в новую сессию, когда решите начать первый этап. Он разрешает **только задачу 1**; дальнейшие этапы выполняются по отдельному запросу.

---

Работай в репозитории Shadow Fleet Detector. Общайся со мной по-русски. Начни разработку **только задачи 1: чистые типы и нормализация синтетических AIS-данных** из `docs/superpowers/plans/2026-11-14-first-development.md`. Пока не создавай БД, сборщик, API, фронтенд и не запускай приложение.

Сначала прочитай `AGENTS.md`, `docs/context.md`, `docs/decisions.md`, `docs/handoff/README.md`, `docs/handoff/implementation-contract.md`, задачу 1 плана и `docs/licenses.md`. Моё указание в этом промпте разрешает реализацию задачи 1, несмотря на историческую запись о стадии проектирования; остальные ограничения сохраняются. Не переписывай AGENTS.md и не объявляй весь проект утверждённым.

Проверь `git status --short` и не перезаписывай существующие изменения. Соблюдай разрешённые пути задачи, используй синтетические фикстуры, не сохраняй реальные AIS payload и секреты. Проверь точные поля REST и MQTT по официальной документации и локальным исследованиям; если проверить не удалось, явно сообщи, что адаптер заблокирован, и не выдумывай поля. Не выполняй сетевые запросы к живому AIS в тестах.

Используй только локальное изолированное Python-окружение, если доступен Python 3.12. Настрой необходимые для задачи зависимости и зафиксируй версии; не устанавливай и не меняй системный Python. Напиши проверки из задачи 1, реализуй только необходимое, запусти их и lint. В отчёте приведи реальные команды и результаты, изменённые файлы, обнаруженные расхождения и невыполненные проверки.

Собственная лицензия проекта не выбрана: не создавай LICENSE и не назначай лицензию за владельца. Для добавленных зависимостей запиши источник, версию и проверенную лицензию; лицензию данных Fintraffic учитывай отдельно. Не делай commit, push или deploy без моего отдельного указания. В конце остановись и жди следующую задачу.
