1. **Начать с контекста.** Прочитать `AGENTS.md`, [контекст](../context.md), [журнал решений](../decisions.md) и [пакет передачи](README.md). Выполнить `git status --short --branch` и `git branch -avv`; проверить текущую ветку, базовый коммит и чужие правки. Не переключать грязный каталог на другую базу.
2. **Подготовить точку передачи.** Сверить пакет с [контрактом](implementation-contract.md) и [планом семи задач](../superpowers/plans/2026-11-14-first-development.md). Перед добавлением файлов проверить [лицензии](../licenses.md), исключить секреты и сырые данные. После указания на коммит сохранить проверенные файлы в `codex/research-handoff`; записать SHA и проверить, что файлы пакета читаются из этого коммита.
3. **Получить задание и выбрать базу.** Начинать разработку только после отдельного указания владельца на номер задачи. Для первой задачи взять проверенный коммит пакета; для следующих — принятый коммит со всеми зависимостями, перечисленными в плане. Из чистого checkout создать ветку командой `git switch -c codex/task-01-ais-normalization <проверенный-SHA>` (для первой задачи). Если текущий каталог занят незакоммиченными правками, использовать отдельный worktree на том же SHA и проверить его статус перед передачей.
4. **Передать одну задачу.** Указать модели путь к checkout, ветку, базовый SHA и номер задачи. Использовать [первый промпт](first-prompt.md) или [протокол продолжения](execution-protocol.md). Первая задача работает на синтетических AIS-данных; запрос к живому источнику допускается только по отдельному указанию. Не трактовать аномалии AIS как доказательство нарушения.
5. **Принять результат.** Сверить diff с разрешёнными файлами и критериями плана, проверить реальные результаты тестов и линта, записать ограничения и следующий шаг в `docs/development/progress.md`. Провести независимое ревью перед задачами 3 и 4 и после задачи 7. При провале проверки исправлять текущую задачу; не передавать её как завершённую.
6. **Закрыть этап.** Коммит, отправка на GitHub и слияние — по указанию владельца. Зафиксировать принятый SHA для следующей сессии. Не открывать следующую задачу без явного указания на неё.
