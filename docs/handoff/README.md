# Передача проекта модели-разработчику

2026-11-14 · **Draft для согласования; разрешения начать разработку пока нет.**

Владелец попросил максимально подробный план для недорогой модели и прямо запретил начинать реализацию в текущем запросе. Этот пакет содержит только документацию.

## Можно ли начинать?

Да, после явного разрешения владельца можно начинать ограниченный локальный срез: сначала синтетические AIS-контракты и нормализация, затем текущие позиции в БД, сборщик, API и карта. Фундамента достаточно для такого начала. Доказательств готовности глобального сервиса, круглосуточного потока и детектора теневого флота пока нет.

Не нужно ждать завершения всех исследований для первого unit test. Нельзя превращать удачные короткие пробы в обещание покрытия, качества или SLA. Самые рискованные места — сверка REST/MQTT и восстановление — выделены в отдельные проверяемые задачи.

## Предлагаемые решения для старта

| Область | Предложение | Статус |
|---|---|---|
| Первый результат | Локальная региональная карта Fintraffic; сначала чистый нормализатор | Draft |
| Runtime | Python 3.12, стандартный venv + pip, pyproject.toml; точные совместимые версии зависимостей закрепить при исполнении | Draft; не обещание наличия окружения |
| БД | PostgreSQL/PostGIS; SQL-миграции с журналом, psycopg; без ORM | Draft |
| Процессы | Один writer collector и отдельный read API; один репозиторий | Draft |
| API/UI | FastAPI; Vite + TypeScript + MapLibre; без UI-фреймворка для первого экрана | Draft |
| Работа модели | Одна задача на сессию, фактический отчёт и проверка перед переходом | Рекомендация |
| Собственная лицензия | Не выбрана; автоматически не создавать LICENSE | Подтверждённый незакрытый вопрос |
| Дизайн | Минимальная функциональная карта; финальное художественное направление отдельно | Ранее согласованная отсрочка подробного дизайна |

Версии инструментов выше — предлагаемые целевые семейства, не результат свежей проверки совместимости. Исполнитель проверяет официальную документацию перед фиксацией lock-файлов. Если Python 3.12 отсутствует, он сообщает об этом и не устанавливает/не меняет системный Python самовольно.

## Что не блокирует первые задачи

Выбор подложки, финальный визуальный дизайн, собственная лицензия, глобальное покрытие и правила теневого флота не нужны для локальных синтетических тестов. Они блокируют соответствующие последующие результаты: публичную карту, лицензированный релиз, глобальные обещания и аналитические метки.

Нельзя давать дешёвой модели задание «сделай весь продукт». Первый законченный результат — нормализатор с проверяемыми входами и выходами. Большой план нужен ей как карта проекта, а не как разрешение сразу реализовать всё.
