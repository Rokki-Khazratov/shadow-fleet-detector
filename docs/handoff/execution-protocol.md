# Как передавать работу по этапам

План разбит на семь зависимых задач. Начните с [первого промпта](first-prompt.md). Для каждого следующего этапа создавайте новую сессию или очищайте контекст после сохранения отчёта предыдущей.

Шаблон следующего промпта:

```text
Работай по-русски в Shadow Fleet Detector. Выполни только задачу N из
`docs/superpowers/plans/2026-11-14-first-development.md`.
Прочитай AGENTS.md, docs/context.md, docs/decisions.md,
docs/handoff/implementation-contract.md, план и предыдущий отчёт
`docs/development/progress.md`. Сохрани чужие незакоммиченные изменения.
Проверь зависимости задачи и актуальность источников. Реализуй и проверь
только указанный этап, сообщи точные результаты проверок и ограничения.
Не делай commit, push, deploy и не переходи к следующему этапу без указания.
```

Замените N на номер. Если предыдущий этап отсутствует или тесты не проходят, попросите модель сообщить блокирующее расхождение и не маскировать ошибку. Перед задачами 3, 4 и после 7 полезно дать более сильной модели diff, контракты и вывод тестов для независимого ревью.

Каждый отчёт должен содержать: что сделано; список файлов; команды и фактические результаты; что не запускалось; незакрытые вопросы. Запрещено считать запланированные проверки пройденными. Сетевой smoke живого источника проводится только по отдельному указанию владельца с лимитами из задачи 7.
