# Архивы AIS и внешние свидетельства: проверка доступа

Проверено **2026-11-14**. Исследование источников до разработки; стек и загрузка больших архивов не утверждаются. Ниже различаются прочитанная документация, успешный запрос метаданных и полученные данные: полные AIS-архивы не скачивались; получены две производные исторические позиции через Kystdatahuset, CSV-префикс NOAA и небольшой CSV OpenSanctions. Содержимое строк не сохранено. API с ключами не вызывались, формы заказа не отправлялись.

## NOAA: рабочий адрес отличается от старого

[InPort Nationwide AIS 2024](https://www.fisheries.noaa.gov/inport/item/73064) описывает позиции сети USCG с частотой, сокращённой до одной минуты. Это обработанный продукт, а не все исходные радиосообщения. Alaska исключена; с 2024 года часть неверных/пустых атрибутов исправляется через AVID. Метаданные указывают отсутствие ограничений доступа, а в Use Constraints — применение для coastal/ocean planning. Поэтому здесь не объявляется универсальная лицензия CC0 и не делается вывод о любых сценариях перепубликации.

Практическая проверка:

- Старый [каталог ZIP 2024](https://coast.noaa.gov/htdata/CMSP/AISDataHandler/2024/index.html) существует, но ссылка AIS_2024_01_01.zip дала **404** и через web, и через прямой HEAD.
- Актуальная ссылка из InPort ведёт в [Azure-каталог CSV 2024](https://noaaocm.blob.core.windows.net/ais/csv2/csv2024/index.html), GET 200.
- [ais-2024-01-01.csv.zst](https://noaaocm.blob.core.windows.net/ais/csv2/csv2024/ais-2024-01-01.csv.zst): **HEAD 200**, Content-Length **196492824**, Last-Modified **2026-03-24 13:23:19 GMT**. При HEAD тело не читалось; ниже — отдельная проверка префикса через Range.
- [AccessAIS](https://marinecadastre.gov/accessais/) сообщает, что сервис заказа по AOI сейчас недоступен. Нельзя обещать получение маленького среза через этот UI.

**Проверка формата:** HTTP Range `bytes=0-65535` вернул **206** с указанным диапазоном. Из префикса потоком извлечены заголовки и **1 239 полных строк**, последняя неполная строка отброшена. `zstd` завершился с кодом 1 из-за незавершённого скачивания; это результат чтения префикса, а не проверка целостности файла. Схема содержит 17 полей, включая `base_date_time`, `longitude`, `latitude`, `mmsi`, `imo`, `transceiver`; [список и хеш префикса](../../research/probes/results/noaa_range_2026-11-14.json). Координаты и идентификаторы не сохранены.

Префикс не репрезентативен для всего дня. Для выбранного района позже нужен полный датированный архив с отдельной проверкой целостности и прав либо другой доступный API с фильтром.

## Danish DMA: доступность каталога пока не доказана

[Официальная страница DMA](https://www.dma.dk/safety-at-sea/navigational-information/ais-data) подтверждает бесплатную историю в CSV, упакованную в ZIP, со ссылкой на [aisdata.ais.dk](https://aisdata.ais.dk/). Web-инструмент получил timeout; прямой GET — connection reset. Это результат из текущей среды, а не доказательство глобального отказа сервиса. Список дат, размеры и конкретный sample не установлены.

[Политика DMA](https://www.dma.dk/safety-at-sea/navigational-information/ais-data/ais-data-management-policy) связывает доступ с датским PSI-законодательством и не гарантирует правильность/непрерывность AIS. В просмотренном материале не установлена точная стандартная лицензия на исторические bulk-файлы. Нельзя переносить условия персонального online-доступа на историю или приравнивать free download к неограниченной публичной ретрансляции.

**Следующий предмет проверки:** открыть каталог из другой сети, выбрать один конкретный доступный ZIP, проверить заголовки и сопровождающие условия. Контакт по историческим данным на странице сейчас относится к Danish Emergency Management Agency; это повод проверять владельца сервиса, а не полагаться на старые ссылки FTP.

## Kystverket: самый явный интерфейс малого исторического заказа

[HAIS](https://hais.kystverket.no/) принимает даты и выбранное судно либо нарисованную область (до пяти областей), выдаёт CSV или Parquet по ссылке в email. На форме указан максимум один год данных в заказе. Фильтр ship type сам по себе недостаточен: нужно судно или геометрия. Это ограничение размера периода заказа, не доказательство наличия только одного года истории.

[Описание HAIS](https://hais.kystverket.no/about) устанавливает NLOD и географию: норвежская экономическая зона, зоны Svalbard/Jan Mayen; рыболовные суда менее 15 м и прогулочные менее 45 м исключены. [Общая страница доступа](https://www.kystverket.no/sjotransport-og-havn/ais/tilgang-pa-ais-data/) требует указания Kystverket при внешнем использовании. Это не глобальный архив.

**Конкретный малый sample:** один день, небольшая область внутри Norwegian EEZ, формат Parquet или CSV. Геометрия, даты и email ещё не выбраны; заказ не отправлен, фактическая схема, объём, время подготовки и доступный календарный диапазон не подтверждены. Не следует писать «sample получен» по одному наличию формы.

### Дополнительно: исторический API действительно вернул данные

Прочитан официальный [OpenAPI Kystdatahuset](https://kystdatahuset.kystverket.no/ws/swagger/v1/swagger.json). Проверен read-only POST [positions/within-bbox-time](https://kystdatahuset.kystverket.no/ws/api/ais/positions/within-bbox-time), без авторизации, с JSON:

```json
{"bbox":"5.20,59.30,5.40,59.50","start":"202601011000","end":"202601011005","minSpeed":0}
```

Получено **HTTP 200, success=true, msg пустое, data: 2 строки по 12 полей**. Времена: 2026-01-01T10:01:36 и 10:04:36. Тело ответа осталось в оперативной памяти; MMSI и координаты не опубликованы. Первый более узкий bbox из примера документации вернул HTTP 200 / success=true / 0 строк: пустой результат нельзя трактовать как недоступность API.

**Migration notes, подтверждённые и схемой, и заголовком ответа:** с 2026-11 позиции производятся из вершин треков, а не отдельных AIS-сообщений. Треки старше примерно месяца упрощены до максимум одной позиции за 30 секунд на судно. COG/SOG, heading, ROT и соседние метрики вычисляются; message_nr всегда null. Временно доступны данные только с 2026-01-01; возвращение истории с 2016 года заявлено как будущее. MinSpeed сравнивается строго и относится к вычисленному SOG, поэтому minSpeed=0 исключает неподвижные точки.

**Следствие:** малый исторический sample действительно получен, но это производные позиции; использовать его для качества raw-AIS gap detection нельзя без учёта упрощения и фильтра скорости. Эти детали относятся к Kystdatahuset endpoint, не автоматически к CSV/Parquet HAIS.

## GFW: события отдельно от сырых треков

[Events API](https://api-doc.globalfishingwatch.org/our-apis/documentation/docs/v3/events) даёт apparent fishing, encounters, loitering, port visits и gaps; поддержка типов судов зависит от события. Например, перечень encounter-пар ограничен и не равен любым двум судам. [Руководство карты](https://globalfishingwatch.org/user-guide/) отдельно сообщает, что скачать AIS vessel tracks и VMS из публичной карты нельзя. Наличие событий не доказывает доступ к underlying raw AIS.

[Get All Events](https://globalfishingwatch.org/our-apis/documentation/docs/v3/events/get-all-events) описывает Bearer token, фильтры дат/судов/datasets и пагинацию. Для малого теста достаточно одного dataset и limit=1 с коротким периодом. Ответ не запрашивался: ключа в рамках исследования нет; пример документации не является результатом API.

[Условия API](https://globalfishingwatch.org/our-apis/documentation/docs/license-rate-limits): некоммерческое использование CC BY-NC 4.0, атрибуция (например, «Powered by Global Fishing Watch.» со ссылкой), лимиты 50 000 запросов в день и 1 500 000 в месяц. Токен нельзя публиковать в клиентском интерфейсе. Дополнительно следует проверять ограничения конкретного dataset и третьих сторон. Лицензия открытого алгоритма GFW и условия данных GFW — разные предметы.

**Предложение:** сохранять GFW-event как внешнее утверждение с версией dataset и временем получения; собственные gap/encounter хранить отдельно. Термин AIS off в API не превращает отсутствие наблюдений в доказанное намеренное отключение.

## OpenSanctions: малый точный артефакт найден, актуальность ограничена

[Некоммерческий bulk-доступ](https://www.opensanctions.org/docs/commercial/exemption/) разрешён без регистрации и API key под CC BY-NC 4.0; бесплатный API key — отдельный grant, а не автоматическое право. [Документация обновлений](https://www.opensanctions.org/docs/bulk/updates/) публикует стабильные latest-адреса и metadata index.json.

Для малого структурного теста найден [UN Security Council 1718 Designated Vessels List](https://www.opensanctions.org/datasets/un_1718_vessels/). Реальный GET [index.json](https://data.opensanctions.org/datasets/latest/un_1718_vessels/index.json) вернул 200:

| Поле | Значение из metadata |
|---|---|
| version | 20261105084407-fbp |
| updated_at | 2026-11-05T08:44:07 |
| targets.simple.csv | 20 374 байта |
| entities.ftm.json | 107 515 байт |
| source.csv | 15 799 байт |

Точный [версионированный CSV](https://data.opensanctions.org/artifacts/un_1718_vessels/20261105084407-fbp/targets.simple.csv) и [FTM JSON](https://data.opensanctions.org/artifacts/un_1718_vessels/20261105084407-fbp/entities.ftm.json) указаны в metadata. Прочитан только CSV: HTTP 200, **59 строк `Vessel`**, поле `identifiers` непустое в 58 строках, `aliases` — в 15. Это не подтверждает валидный IMO и не доказывает совпадение с AIS. [JSON с агрегатами и хешем файла](../../research/probes/results/opensanctions_vessel_schema_2026-11-14.json). FTM JSON не загружался; это более подходящий кандидат для последующей проверки происхождения и структуры идентификаторов. Источник данных — OpenSanctions, [CC BY-NC 4.0 и условия](https://www.opensanctions.org/docs/commercial/exemption/), опубликованы только производные агрегаты.

**Критичная оговорка:** страница набора указывает coverage current until **2020-06-04**, frequency **not automated**. Свежая дата обработки не означает свежесть первичного списка. Этот маленький набор подходит для проверки формата, а не для вывода о текущем санкционном статусе судна. Для актуальной проверки нужен датированный первичный документ соответствующего органа; например, [OFAC Sanctions List Service](https://ofac.treasury.gov/sanctions-list-service) публикует собственные списки, включая суда.

Не считать любую запись OpenSanctions санкцией: [default collection](https://www.opensanctions.org/datasets/default/) включает более широкий набор лиц/организаций повышенного публичного интереса. [Sanctions collection](https://www.opensanctions.org/datasets/sanctions/) уже по назначению, но также требует чтения источников, режима, дат и корректного сопоставления IMO/MMSI/названий.

## Что хранить в доказательной основе

Предложение исследователя, не утверждённая схема: source URL; dataset/version; retrieved_at; observation/effective date; лицензия и атрибуция; checksum артефакта; исходный идентификатор; способ сопоставления судна; статус «наблюдение / внешнее утверждение / собственная гипотеза». AIS-пробел, санкционная запись и принадлежность к теневому флоту остаются разными утверждениями.

Сырые файлы и ключи — вне Git. Эта проверка устанавливает доступность документации и отдельных metadata endpoints; она подтверждает получение двух производных исторических позиций, но не качество сырого AIS. Следующий доказуемый шаг — получить репрезентативный разрешённый малый набор, измерить фактические поля/время/географию/пропуски и только затем выбирать компоненты обработки.
