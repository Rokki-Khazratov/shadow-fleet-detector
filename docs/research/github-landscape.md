## pyais

[README](https://github.com/M0r13n/pyais/blob/main/README.md), [пакет](https://github.com/M0r13n/pyais/tree/main/pyais), [примеры](https://github.com/M0r13n/pyais/tree/main/examples), [тесты](https://github.com/M0r13n/pyais/tree/main/tests). Чистый Python для AIS AIVDM/AIVDO: подходит, когда источник даёт сырые NMEA строки, например TCP-поток Kystverket. Граница ответственности — декодер, а не глобальный поставщик данных, система идентичности или детектор теневого флота. Для готового JSON от Digitraffic отдельный NMEA-декодер не нужен. Проверить handling multi-fragment, контрольные суммы, неизвестные типы сообщений и скорость на нашем потоке до включения.

## AISdb

[README](https://github.com/MAPS-Lab/AISdb/blob/master/README.md), [Python](https://github.com/MAPS-Lab/AISdb/tree/master/aisdb), [Rust core](https://github.com/MAPS-Lab/AISdb/tree/master/aisdb_lib), [receiver](https://github.com/MAPS-Lab/AISdb/tree/master/receiver). Проект сочетает Python-интерфейс, Rust и варианты хранения SQLite/PostgreSQL/TimescaleDB; для нас интересны готовые идеи импорта, запросов траекторий и локального исследования. Это потенциально крупная инфраструктурная зависимость. Лицензия AGPL-3.0 требует отдельной оценки совместимости с будущим размещением сервиса и лицензией нашего кода. Не выбирать без маленькой пробы на реальных данных и проверки API/развёртывания.

## aisstream

[Репозиторий](https://github.com/aisstream/aisstream) содержит только README в корне: это вход в сервис, не open-source реализация сервера. [Актуальная документация](https://www.aisstream.io/documentation/) описывает WebSocket, обязательные ключ и bounding boxes, JSON-подписку, типы сообщений и лимиты. Данные приходят бинарными UTF-8 JSON фреймами. Сервис может помочь с текущими позициями и другими AIS-сообщениями. Реальное покрытие, права хранения/публикации, надёжность и объёмы ещё не проверены. Без ключа проверена только страница документации.

## Global Fishing Watch: gaps и encounters

[pipe-gaps](https://github.com/GlobalFishingWatch/pipe-gaps) и [pipe-encounters](https://github.com/GlobalFishingWatch/pipe-encounters) — специализированные аналитические pipeline на Python/Apache Beam, не готовый live-картографический продукт. Изучать определения событий, обработку ошибок покрытия и тестовые примеры; переносить целиком лишь после сравнения эксплуатационной сложности. Gap означает разрыв наблюдений, а не доказанное отключение. Encounter означает обнаруженное пространственно-временное сближение, а не доказанную перегрузку. Их API-клиент/данные и открытый код имеют разные условия доступа.

## MapLibre GL JS

[README](https://github.com/maplibre/maplibre-gl-js/blob/main/README.md), [архитектура](https://github.com/maplibre/maplibre-gl-js/blob/main/ARCHITECTURE.md). Движок интерактивной карты и векторных тайлов, релевантен при переходе к UI. Не поставляет AIS, корабли, расследования или право на базовые тайлы. Для большого числа судов нужно проверить кластеризацию/слои, обновление объектов и поведение у антимеридиана. GitHub API вернул NOASSERTION, поэтому лицензию читать в самом LICENSE.txt, не полагаться на API классификатор.

## Kepler.gl

[README](https://github.com/keplergl/kepler.gl/blob/master/README.md), [пакеты](https://github.com/keplergl/kepler.gl/tree/master/src). Богатый инструмент для исследования геоданных и визуального анализа; может ускорить внутренние прототипы и проверку траекторий. Для специального публичного интерфейса с досье, доказательствами и контролем свежести может оказаться слишком общим и тяжёлым. Сравнить с MapLibre только после определения требований к карте и размера наборов.

## Практический вывод

Слои выбирать отдельно: поставщик AIS → парсер соответствующего формата → хранение → воспроизводимые детекторы → evidence → карта. Начать с уже проверенного REST JSON Digitraffic для контракта и ошибок, затем испытывать streaming при доступе к ключу и лицензии. pyais нужен для NMEA; MapLibre — кандидат UI позже; GFW pipeline — архитектурные ориентиры; AISdb — возможная инфраструктура с отдельным лицензионным решением. Ни stars, ни README не подтверждают пригодность под наши объёмы или права на данные.
