# Готовность к старту разработки

Статус: **есть основание проектировать первый региональный срез; разработка приложения ещё не начата**. Рекомендуемый объём ниже предназначен для отдельного решения о старте. Он не меняет общую цель: карта мира, все типы судов, досье и независимые слои доказательств.

| Проверка перед стартом | Состояние | Что это меняет |
|---|---|---|
| Доступный снимок и поток | Подтверждено для Fintraffic REST и MQTT; Kystverket HTTP отвечает | Первый срез можно спланировать без ключей. Глобальный live-источник не доказан. |
| Разбор критичных полей | REST `timestampExternal` в мс; MQTT `time` в с; Kystverket `date_time_utc` без смещения трактуется как UTC по контракту | Для каждой записи нужны `provider_time`, `received_at` и происхождение времени. Не называем возраст записи задержкой от передатчика. |
| Покрытие и свежесть | Измерены короткие региональные окна; нет наблюдений за полными сутками | Показываем регион источника, последний успешный ответ и возраст позиции. Отсутствие наблюдения не равно отсутствию судов. |
| Права для первого среза | Fintraffic публикует условия CC BY 4.0 и атрибуции; у Kystverket условия и ограничения проверяются по конкретному интерфейсу | Рекомендуемый первый срез использует только Fintraffic. Перед публичным показом применить атрибуцию и проверить карту/тайлы отдельно. |
| Исторические контрольные данные | Проверены малые выборки NOAA и Kystdatahuset; норвежский API отдаёт производные вершины | Подходят для испытаний формы трека в пределах известных ограничений. Валидация raw AIS gap detector остаётся открытой. |
| Реальные внешние свидетельства и identity | Есть исторический CSV для схемы; актуальная привязка к первичному источнику не доказана | Слой теневого флота остаётся вне первого среза. Не присваиваем реальные метки по синтетике, имени или AIS-аномалии. |
| Стек и объём старта | Решения не утверждены | Сначала утвердить объём первого среза; выбор хранения/интерфейса привязать к измерениям и текущим требованиям. |

## Предложение для первого среза (draft)

Один региональный источник: Fintraffic. REST — начальное состояние и повторный снимок после потери потока; MQTT — изменения после подписки. Сначала открыть подписку и временно буферизовать обновления, затем взять снимок и применить только более новые записи по времени поставщика. При разрыве сохранять возраст последней позиции, обозначать состояние источника и после возврата сверять новый снимок с буфером. REST и MQTT не гарантируют полноту истории. Для одного источника разрешён ключ наблюдаемого сигнала `source + MMSI`; постоянный ID судна и слияние с Kystverket — отдельный этап.

| Проверка первого среза | Проверяемый исход |
|---|---|
| Единицы времени | Один UTC-момент из REST мс и MQTT с сравнивается на общем масштабе; AIS-секунда 0–63 не используется как Unix-время. |
| Гонка снимка и потока | MQTT-запись, поступившая до загрузки REST и имеющая более новое время, остаётся последней после загрузки. |
| Равные/запаздывающие записи | Повтор сообщения не создаёт новую точку. Старое сообщение не откатывает позицию. При одинаковой секунде с разными координатами сверка не выдаётся за достоверный порядок; конфликт сохраняется для диагностики. |
| Неизвестные значения | 511 heading, 360 COG, 102.3 SOG в Fintraffic превращаются в неизвестное значение; без геометрии запись не рисуется. |
| Разрыв и устаревание | После отключения здоровый поток не имитируется. Возраст позиции продолжает расти, время и источник остаются видимыми. |
| Карта вне проверенного региона | Пользователь видит отсутствие данных источника, а не гарантированное отсутствие судов. |
| Воспроизводимость | Для проверки используем синтетические случаи и датированные агрегаты; не помещаем сырые треки в Git. |

Пороги 5 минут и 1 час в [замерах](ais-transport-comparison.md) — исследовательские интервалы, не SLA и не согласованный UX. Для более широкого запуска ещё нужны измерения в разное время суток, правила привязки двух источников к одному судну, отдельная проверка AISstream и условия хранения данных для каждого интерфейса. Закрытие этих пунктов не требуется, чтобы спланировать локальный срез с одним источником, но без них нельзя обещать глобальное покрытие, надёжность истории или проверку принадлежности к теневому флоту.
