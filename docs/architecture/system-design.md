# System design — draft 2026-11-13

## Область
Глобальная карта доступных текущих AIS-позиций всех типов судов, досье по выбору, история как дополнительный режим, отдельные слои аномалий и внешних свидетельств. Покрытие, свежесть и пропуски видимы. Бесплатные источники — текущее ограничение. Это концепция, не выбранная реализация.

## Потоки
Источник → source adapter → неизменённая диагностическая запись (по разрешению лицензии) → нормализация → проверка координат/времени → дедупликация → история позиций → проекция последней позиции → карта/досье. Независимый поток внешних утверждений → provenance → разрешение идентичности → слой evidence. Движки аномалий читают нормализованную историю и выпускают события с версией правил, параметрами и альтернативными объяснениями.

## Границы компонентов
Adapter отвечает только за транспорт, лимиты, ошибки и схему конкретного источника. Нормализатор создаёт единый контракт и явно отмечает отсутствующие значения. Resolver сопоставляет MMSI, IMO, call sign и имена с интервалами действия и конфликтами. Projection хранит текущее состояние для карты. Event engine строит воспроизводимые события. Evidence registry сохраняет ссылку на первичный источник, дату наблюдения и дату публикации. Query API (позже) отдаёт только разрешённые для публикации поля.

## Предлагаемые варианты
A: Python + SQLite/GeoPackage для локального исследования: низкий порог, ограниченная многопользовательская карта. B: Python + PostgreSQL/PostGIS: пространственные запросы, индексы и атомарные upsert; выше эксплуатационная цена. C: потоковая распределённая инфраструктура: масштабируемость ценой ранней сложности. Предложение: сначала доказать контракты JSON и качество источников, затем B при переходе к приложению; не фиксировать стек до оценки объёма и лицензий.

## Ключевые решения для проверки
Глобальная карта может показывать региональные источники, но обязана отдельно показывать фактическую географию и возраст данных. Последняя позиция выбирается по времени наблюдения, а не времени получения; позднее сообщение не должно откатывать карту. Повторное получение одной позиции не создаёт дубликат. AIS MMSI не является вечной идентичностью корпуса. Санкции, AIS-события и атрибуция к теневому флоту имеют разные поля/статусы. Источник может запретить хранение или повторную публикацию; такой адаптер ограничивает downstream. Формула хранения: число сообщений/сек × средний размер нормализованной записи × период хранения; измерить на реальных потоках до capacity planning.

## Надёжность и наблюдаемость
Фиксировать время последнего успешного чтения, ошибки, age распределение, пропуски, дубликаты, объём потока по источнику и версии схем. При разрыве потока показывать stale state. Возобновление с backoff; отсутствие replay у источника фиксируется как пробел, не заполняется выдуманными позициями. Границы карты через антимеридиан требуют двух bbox или другого проверенного представления. Все времена в UTC с исходной точностью.

## Безопасность и права
Ключи в секретах окружения, серверные соединения с поставщиками; публичный интерфейс не получает их. Каждая запись несёт source_id, лицензионную политику, возможность хранения/публикации, attribution. Публичная карта не должна служить доказательством нарушения без проверки человека.
