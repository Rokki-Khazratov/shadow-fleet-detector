# Граница локального выпуска — draft, 2026-11-15

| Этап | Локальный результат | Условия дальнейшего расширения |
|---|---|---|
| 1. Текущие позиции | Сборщик, PostGIS, API и карта; физический перезапуск тестовой БД проверен | Датированные ограниченные живые прогоны сборщика и замеры покрытия |
| 2. История | Опциональная запись, ограниченное окно, точки без соединяющей линии, очистка по TTL | Проверенный набор архивных данных и решение о его правах и хранении |
| 3. Досье | Датированные ручные связи и внешние записи со ссылками; неоднозначность видна | Проверка точных реестров и первичных источников; правила разрешения конфликтов на реальных данных |
| 4. Качество AIS | Интервалы между сохранёнными точками, конфликты и сдвиги времени | Валидация на известных кейсах с учётом покрытия и ошибок приёма |
| 5. Локальная готовность | Один сценарий с отдельной БД и ролью чтения; без платных сервисов | Для публичной среды: права на размещение, лицензия проекта и notices, авторизация, защита API, эксплуатационный план и географическое покрытие |

Локальная проверка использует синтетические сведения. «Пусто», «усечено» и «не настроено» означают разные ситуации; ни одна из них не определяет статус судна. Источники не загружаются автоматически сверх Fintraffic при явном запуске сборщика. Публичные данные, дополнительные регионы и публичный запуск в текущую приёмку не входят.
